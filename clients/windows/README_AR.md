# نسخة Windows

هذه نسخة سطح مكتب Electron تعرض نفس نظام Hostinger وقاعدة بياناته (ليست قاعدة محلية منفصلة).

1. شغّل npm install من داخل clients/windows.
2. شغّل npm start للتجربة.
3. شغّل npm run dist لبناء EXE محلياً على Windows، أو شغّل GitHub Actions workflow باسم Windows.
4. أول تشغيل: أدخل رابط موقع المحاسبة بصيغة https://... مرة واحدة.
5. سجّل الدخول بنفس بيانات مدير النظام التي أنشأتها على الويب.

**تنبيه:** البناء من المصدر موجود في المستودع. لا يُعد ملف EXE جاهزاً للتنزيل إلا بعد نجاح Workflow وظهور Artifact. النسخ غير موقعة رقمياً افتراضياً وقد يعرض Windows SmartScreen تحذيراً.

لا تضع كلمات مرور MySQL في هذه النسخة. الواجهة تتصل حصراً بالـHTTPS API.
