# نسخة Android

عميل Android WebView أصلي يتصل بنظام NineSoft على Hostinger عبر HTTPS. لا يحفظ دفتر أستاذ محلياً ولا يحتاج مفاتيح قاعدة بيانات على الهاتف.

## بناء APK
- استخدم Android Studio مع Java 17، Android SDK 35، وGradle 8.13.
- افتح clients/android كمشروع Gradle، ثم نفذ gradle assembleDebug أو من Android Studio Build APK.
- أو شغّل GitHub Actions: workflow Android APK، ثم نزّل الـArtifact بعد نجاح البناء.
- بعد تثبيت التطبيق: أدخل رابط الخادم https://... مرة واحدة ثم سجّل الدخول.
- assembleDebug ينتج APK تجريبياً موقّعاً بمفتاح Debug. التوزيع الرسمي يتطلب مفتاح إصدار خاص بك وتهيئة signingConfigs.

**نطاق الإصدار:** يحتاج شبكة؛ لا يوجد وضع offline أو مزامنة محلية. يمنع التطبيق الالتفاف على أخطاء شهادات HTTPS.


## تحديث 30 أكتوبر: تجربة محلية فورية
- عند أول تشغيل بدون رابط محفوظ، يفتح التطبيق واجهة NineSoft مباشرة من ملف demo.html المضمن داخل APK.
- الأقسام والتصميم والخطوط والواجهة تستخدم نفس assets/{core.js,pages.js,actions.js,style.css,logo.svg} في الويب.
- البيانات وعمليات حفظ الفواتير والتجارب محلية **وهمية** داخل تخزين WebView للهاتف، دون إرسالها لقاعدة MySQL.
- زر «ربط Hostinger» يفتح شاشة الخادم الفعلي، وزر «إعادة التجربة» يمسح بيانات العرض فقط.
- بعد ربط الخادم يبقى سلوك الويب الحالي كما كان؛ لا تخلط التجربة مع بيانات مالية فعلية.
- عند تحديث APK من GitHub قد تختلف شهادة توقيع Debug؛ إذا رفض الهاتف تثبيت التحديث، أزل نسخة الاختبار السابقة وثبت الجديدة.
- يلزم GitHub Actions ناجح وفحص APK على هاتف حقيقي قبل الجزم بأن الواجهة تعمل على كل الأجهزة.
