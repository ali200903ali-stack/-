# خطة التحقق قبل التشغيل

## اختبارات تلقائية في GitHub
- PHP lint على جميع الملفات.
- Node syntax checks للملفات الثلاثة الخاصة بالواجهة وWindows.
- MariaDB test مع إنشاء قاعدة البيانات والتأكد من:
  1. إنشاء صنف وحسابات وفرع وعميل ومورد.
  2. قيد افتتاحي متوازن.
  3. بيع آجل، نقص مخزون، وتسجيل ذمم العميل.
  4. إعادة طلب ترحيل فاتورة لا تغير الأرصدة.
  5. شراء آجل، زيادة مخزون، وتكلفة متوسطة.
  6. قبض وصرف للموردين والعملاء.
  7. بيع نقدي ثم مرتجع نقدي.
  8. مجموع المدين = مجموع الدائن.

## اختبارات يدوية لازمة على Hostinger
- TLS/HTTPS، تسجيل الدخول والخروج، منع محاولة الوصول إلى القاعدة أو ملفات backend مباشرة من HTTP.
- جلسة مستخدم cashier لا تقرأ فروعاً أخرى، وviewer لا يرحل ولا يعدل.
- تعدد أجهزة على نفس الشركة وحل تعارض تعديل المسودة.
- محاولة مرتجع أكبر من كمية الأصل، محاولة نفاد مخزون، خصم يتجاوز الإجمالي، وفاتورة بدون أصناف.
- تواريخ عربية، الضرائب، الطباعة، تصدير CSV ونسخ MySQL.
- فتح 19 قسماً على Desktop وMobile وفي Electron وWebView.
- بناء APK وEXE وفحص من جهاز Windows 11 وهاتف Android حديث (لم يتم الادعاء بإجرائها آلياً).
- مراقبة الأخطاء ورسائل Logs ونقاط ضعف CSRF وsession fixation وbrute force وتحديثات التبعيات.

## السياسة
منع الاستخدام المالي الإنتاجي إلى أن يقرّ مسؤول النظام والمحاسب نتائج الاختبارات ومطابقة السياسات المالية الفعلية.
