## التطبيقات
- Web: تطبيق PHP/JS جاهز للنشر على خادم يدعم MySQL، يحتاج إعداد host وبيانات اعتماد وقاعدة فارغة.
- Windows: مصدر عميل Electron وقالب GitHub Actions للبناء؛ لا يفترض أن EXE جاهز دون نجاح Artifact.
- Android: مصدر عميل Java WebView وقالب GitHub Actions لبناء APK تجريبي؛ يلزم توقيع إصدار رسمي عند التوزيع.
- PWA: يعمل عبر HTTPS؛ لا يوجد ترحيل بدون شبكة.

## قيود محاسبية صريحة
- لا يوجد دعم إعادة فتح/حذف قيد مرحّل. التصحيح يتم بقيود تصحيحية محكومة يدويًا وليس حذفاً صامتاً.
- مرتجع المبيعات: الأصل مدفوع كاملاً، والرد نقدي؛ لا تدعم مرتجعات المشتريات أو التسويات المركبة في هذا الإصدار.
- المدفوعات المتقدمة/الأرصدة الدائنة السالبة غير مدعومة في السندات.
- لا يوجد تحويل عملة أو تسعير تفصيلي متعدد مخازن لكل فرع. رصيد الصنف عام، بينما القيود المالية موسومة بالفرع؛ هذا قيد يجب الانتباه له في إدارة المخزون متعددة الفروع.
- لا يوجد نظام ضرائب أو فوترة إلكترونية معتمد من جهة حكومية، ولا إقفال سنوات مالي معتمد.
- لا يوجد دعم Offline Sync. ملفات Windows وAndroid هي عملاء لنظام ويب واحد.
- طباعة الوثائق تتم بواسطة المتصفح / الطباعة إلى PDF، وليست خدمة توليد PDF محاسبي رسمية.
- عملات الأرصدة تعرض بحسب كود واحد عام؛ لا تصرف.
- حدود النظام واختباراته لا تساوي شهادة تدقيق قانوني أو جهوزية لأموال حقيقية.

## الفحص والجودة
يُفحص PHP وJavaScript في GitHub Actions، مع اختبار MySQL تلقائي لسيناريوهات القيود، الفواتير، السندات والمخزون. اطلع على علامة نجاح أحدث Workflow قبل النشر، ثم اختبر على الاستضافة ونظام Windows وهاتف Android حقيقي.
