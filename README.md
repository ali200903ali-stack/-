# NineSoft | نظام ناين سوفت المحاسبي

مشروع عربي RTL لنظام محاسبة ويب قابل للاستضافة على PHP/MySQL مع مصادر عملاء Android وWindows.

> **الحالة:** قيد الإنشاء والتحقق. لا تستعمله بأموال حقيقية حتى اكتمال اختبارات المحاسبة والأمن وإعداد الاستضافة والنسخ الاحتياطية.

مرجع الواجهة: ملف NineSoft.zip المرسل بواسطة مالك المستودع. الواجهة المرجعية HTML كانت تجريبية وغير متصلة بقاعدة بيانات.

اقرأ docs/DEPLOY_HOSTINGER_AR.md و docs/STATUS_AR.md بعد إضافة الملفات.
