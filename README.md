# NineSoft — ناين سوفت للحلول المالية

نظام محاسبي عربي RTL للويب، مع مصدر تطبيق Windows (Electron) وتطبيق Android (Java WebView) يتصلان **بخادم واحد**. بنيت الواجهة استناداً إلى المرجع NineSoft.zip المرسل من مالك المشروع، لكن عمليات دفتر الأستاذ في MySQL وليست في localStorage.

> **مهم:** هذا تنفيذ مستقل أولي قابل للتجربة والتطوير، وليس نسخة مرخصة أو منسوخة من منتج NineSoft التجاري، ولم يجتز حتى الآن تدقيقاً محاسبياً/أمنياً شاملاً يسمح بالتوصية باستخدامه مع بيانات مالية حقيقية. التكاملات الخارجية ليست مفعّلة دون بيانات الاعتماد.

## البنية
- Web: PHP 8.2+ وPDO MySQL + JavaScript بدون npm أو Composer على الاستضافة.
- Database: MySQL 8 أو MariaDB 10.11 مع معاملات InnoDB، أسطر قيود متوازنة، عميل/مورد/صنف/فاتورة/سند/فرع/مستخدم.
- Desktop: Electron WebView/BrowserWindow آمن عبر HTTPS إلى نفس عنوان الويب، ويُبنى EXE.
- Android: Java WebView عبر HTTPS إلى نفس قاعدة البيانات عبر API، ويُبنى APK.
- PWA: يمكن تثبيت رابط الويب كتطبيق خفيف، ولا تُخزن البيانات المحاسبية دون اتصال.

## تجربة محلية سريعة
1. أنشئ قاعدة MySQL جديدة بترميز utf8mb4.
2. انسخ config.example.php إلى config.local.php (ملف محلي غير مرفوع إلى GitHub)، وضع بيانات MySQL، ونص install_token عشوائي طوله 24 محرفاً على الأقل.
3. شغّل PHP من جذر المشروع مع خادم محلي مناسب ودعم Apache أو PHP:
   php -S localhost:8000
4. افتح http://localhost:8000/install.php، أدخل install_token، وسجل مديراً بكلمة مرور قوية. لا تعرض التثبيت على الإنترنت بلا HTTPS.
5. افتح index.php وسجّل الدخول.
6. أنشئ عملاء وموردين وأصنافاً؛ اختبر الفواتير المسودة قبل الترحيل والتقارير.
7. على البيئة الحقيقية لا تستخدم خادم PHP المضمن؛ استخدم Hostinger/Apache+SSL وقاعدة بيانات مع نسخ يومية.

## ما هو موجود فعلياً
- حسابات مدينة/دائنة، فواتير مبيعات ومشتريات ومرتجعات نقدية من فواتير مدفوعة بالكامل، مخزون وتكلفة متوسطة، سندات قبض وصرف، قيود يدوية، دفتر حركة وتقارير ميزان مراجعة وأرباح وخسائر وأرصدة وكشف طرف، إدارة صلاحيات وحسابات وفروع.
- جذر المستودع يمثل تطبيق الويب. clients/windows وclients/android هما مصدر تطبيقين يتطلبان نجاح البناء في GitHub Actions قبل وجود ملفات EXE وAPK فعلية.
- التكامل WASL وواتساب: واجهات توضيحية غير متصلة بمزود؛ لا تدّعي إرسال رسائل أو مزامنة دون API رسمي.

**لا تضع كلمات مرور، مفاتيح API أو config.local.php في هذا المستودع العام.**

## المصدر والترخيص
نظام مستقل مكتوب لهذا المستودع، مستوحى من الواجهة المرجعية المرفقة. لم تُنسخ إليه شيفرة مستودع آخر أو صور ذات ملكية غير مصرّح بها. قبل التوزيع التجاري، اختر رخصة المشروع بما يناسب حقوقك والتحقق من ملكية المراجع التصميمية.
